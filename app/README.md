# Wordsmith app (Flutter, Android)

## Layout

| Path | What's there |
|---|---|
| `lib/engine/` | Pure-Dart game rules with no Flutter imports: puzzle model, board, words, hints, progression, heat, pickup seeding |
| `lib/data/` | The bundled campaign, the profile and settings models, and local storage (shared preferences) |
| `lib/game/` | Riverpod providers, the profile notifier, and `SoloController` (one campaign puzzle) |
| `lib/ui/` | The anvil ring, the mold grid, spark and ember effects, theme, and shared widgets |
| `lib/features/` | Screens: Forge Hall, chapters, puzzle and "Forged!" overlay, profile, settings, credits |
| `assets/` | `campaign/` (generated by `tools/puzzlegen`), `images/`, `audio/`, `icons/`, `fonts/` (see `art/`) |

## Develop

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --debug     # build/app/outputs/flutter-apk/app-debug.apk
```

Build settings come from `--dart-define`s. Without them the app is solo-only:

| Define | What it is |
|---|---|
| `FIREBASE_API_KEY` | `current_key` from the Firebase project's `google-services.json` |
| `API_BASE` | Server URL, e.g. `https://wordsmith-api.<subdomain>.workers.dev` |

Put them in the git-ignored `dart_defines.json` and build with
`flutter build apk --dart-define-from-file=dart_defines.json`. CI passes them
from repository secrets and variables (see `.github/workflows/release.yml`).

The app ID is `com.wordsmithforge.game`. A web build (`flutter build web`) is
used only for automated screenshots during development. The product is
Android-only.
